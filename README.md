# 拦水 · Little Dams

## 一座坝

双击 **试玩拦水.command** 进入近景沙盒。直接拖放岸边的石头和泥土筑坝，按 **空格**或点右上角的**放水**，可以扒开坝上的一处缺口。把小石头拖到大石头上可以堆高，抽走底石时，上层会落下。漏过第一道坝的浅水可以在右侧第二道坝前慢慢蓄起来。岸边的落叶和小树枝可以拖进水里，也可以从水里捞起来。按 **R** 重置溪沟。

## V1.0 三段溪沟

V1.0 第一阶段原型。夏日的山村小沟，沿着上、中、下游捡石头、填泥、筑坝和放水。

## 试玩

在终端将 `--classic` 传给 **试玩拦水.command**。也可在 Godot 4.7.1 里打开 `game/creek.tscn` 后按 F6。自由沙盒没有时间限制。水坝生存有 24 秒和有限的材料，也可以提前放水。

| 操作 | 效果 |
| --- | --- |
| 左键拖动石头或泥土 | 搬走一块材料，松手时按落点摆放 |
| 将材料拖到另一块上 | 堆高一层。暖黄色「＋」提示可以叠放 |
| 从工具栏拖动石头或泥土 | 取出一块新材料。也可按 `1` / `2`，再左击溪沟 |
| 右键，或按 `3` 后左键 | 移除可搬动的材料 |
| 空格 | 扒开上游坝中央，观察洪峰经中游向下游传播 |
| `L` / 漂树叶 | 在水沟入口投一片叶子 |
| `R` / 重来 | 重置当前模式 |

自由沙盒中，试着在下游留一条缝，等上游水蓄起来再放。对比同一座坝堆高前后的出水位置。若一直静置，中游先有泥土慢慢松动，冲开的缺口会让部分积水流出去。

## 实现

地图使用 16×16 像素的 TileMapLayer。场景以 416×176 原生像素渲染，默认窗口使用 3 倍最近邻放大，动态水面和水花分别绘制。材料可以任意落点放置并堆高，搬走底层会让上层落下。三段水量模型分别计算渗流、绕流、低坝漫水与局部冲刷，水和泥沙沿溪沟传到下一段。

## 近景水流调试

在 Godot 中打开 `game/one_dam.tscn`，选择根节点 **OneDam**。检查器里的「近景水流调试」可以调节模拟节奏、通水速度、阻挡高度、冲刷和白沫。当前近景使用一张 64×17 水流网格，上下游共享水深和流量。旧版三段溪沟仍可用 `--classic` 进入。

运行水流回归检查：

```sh
./试玩拦水.command --headless --script res://tests/one_dam_water_test.gd
```

检查涵盖开口与筑坝时的水量账、退水与绕流、低水和满水的开闸阶段、缺口位置导致的破坏差异，以及相同下游泥坝在有洪峰和无洪峰时的结果。
